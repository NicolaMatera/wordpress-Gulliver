# Gulliver - WordPress web project

This repository contains the Gulliver project, developed as a final project for the [Principles of Social Psychology for the Web] course at the [University of Milan-Bicocca].

The exam guidelines required the design and development of a promotional mini-site dedicated to a specific IKEA product. The goal was to build a web interface that would emphasize the product's features and encourage purchase.

## 🗂️ Website Structure:
- Home page
- Product (materials, features, designer, etc.)
- Purchase/promo/flash deal
- Contact details (with information request form and two points of sale)
- News (with at least 3 news items)
- Free-themed page

## 📋 Project Requirements
- Website built in WordPress (no use of languages ​​other than CSS, HTML, PHP, JS)
- Development for one resolution: 1920

## 📦 Submissions:
- **User Personas**
- **Moodboard**
- **Wireframes**
- **Mockup (Figma)**
- **Final Product (WordPress)**
