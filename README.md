# Gulliver - Progetto Web WordPress 🌍

## 🎓 Obiettivo del Progetto ed Esame
Il progetto nasce come elaborato finale per il corso di **Principi di Psicologia Sociale per il Web Design** presso **Università degli Studi di Milano Bicocca**.

La direttiva d'esame richiedeva la progettazione e lo sviluppo di un **mini-sito promozionale dedicato a un prodotto IKEA specifico**. L'obiettivo era costruire un'interfaccia web capace di rispondere a una doppia sfida strategica:
1. **Comunicazione visiva:** enfatizzare le proprietà, il design e le caratteristiche distintive del prodotto.
2. **Persuasione e Conversione:** strutturare il layout e le *Call to Action* in modo da guidare l'utente in modo naturale verso l'acquisto.

Questo repository contiene il codice di **Gulliver**, un progetto web sviluppato come elaborato finale per il corso di **[Inserisci il Nome del Corso]** presso **[Inserisci l'Università]**.

## 📋 Requisiti del Progetto (Requirements)
Per soddisfare le direttive d'esame, lo sviluppo tecnico del progetto ha rispettato i seguenti vincoli:
- **Sviluppo CMS:** Realizzazione esclusiva in ambiente **WordPress**, senza l'ausilio di site-builder visivi (ammesso solo l'utilizzo di CSS, HTML, PHP, e JS personalizzati).
- **Responsive Design Rigoroso:** Il layout è stato progettato e sviluppato per adattarsi perfettamente a 1920px (Desktop).

## 📦 Materiali di Progettazione (Deliverables)
Il progetto non si limita allo sviluppo del codice, ma comprende l'intero flusso di lavoro tipico di un prodotto digitale centrato sull'utente. Durante il corso sono stati prodotti e consegnati i seguenti materiali di ricerca e design:
- **User Personas:** Ricerca sul target di riferimento per guidare le scelte di design e di comunicazione persuasiva.
- **Moodboard:** Definizione dell'identità visiva e dello stile in linea con il brand IKEA.
- **Wireframes:** Progettazione strutturale dell'architettura dell'informazione e dei percorsi di navigazione.
- **Mockup (Figma):** Progettazione dell'interfaccia utente (UI) in alta fedeltà.
- **Prodotto Finale (WordPress):** Il sito web interamente funzionante e pubblicato online.
